# Katiopa - Plateforme Éducative Interactive

Une plateforme éducative moderne qui combine l'apprentissage et le jeu pour rendre l'éducation plus engageante et efficace.

## 🎮 Jeux Disponibles

### 1. LogiQuest
- Jeu de logique avancé
- Suites numériques complexes
- Motifs de formes et couleurs
- Séquences d'échecs
- Système d'indices
- Progression par niveau

### 2. Ludo Mathématique
- Trois niveaux de difficulté
- Mode multijoueur
- Mode contre Okapi (IA)
- Calculs adaptés au niveau

### 3. Math Adventure
- Système de progression
- Animations et effets visuels
- Quatre types d'opérations
- Système de santé et XP
- Récompenses et trophées

## 🚀 Technologies Utilisées

- Next.js
- React
- Chakra UI
- TypeScript
- Framer Motion

## 🛠 Installation

1. Clonez le dépôt :
```bash
git clone https://github.com/ngu-kimuntu/katiopa.git
```

2. Installez les dépendances :
```bash
cd katiopa
npm install
```

3. Lancez le serveur de développement :
```bash
npm run dev
```

## 🌟 Fonctionnalités

- Interface utilisateur moderne et responsive
- Système de progression personnalisé
- Animations et effets visuels engageants
- Mode sombre/clair
- Système de récompenses
- Assistant IA Okapi
